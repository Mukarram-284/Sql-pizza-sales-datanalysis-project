# 🍕 Pizza Sales Analysis Using SQL

## 📌 Project Overview

The **Pizza Sales Analysis Project** focuses on analyzing pizza sales data using SQL to extract meaningful business insights. The project explores sales performance, customer ordering patterns, popular pizza categories, and revenue trends.

By performing Basic, Intermediate, and Advanced SQL queries, this project demonstrates how SQL can be used for data analysis and business decision-making.

## 🎯 Project Objectives

- Analyze overall pizza sales performance.
- Calculate total revenue and total orders.
- Identify the most popular pizza types and sizes.
- Understand customer ordering patterns.
- Analyze sales trends by date and time.
- Identify top-performing pizza categories.
- Calculate revenue contributions and cumulative revenue.

## 🛠️ Tools & Technologies

- **SQL** – Data querying and analysis.
- **Relational Database** – Storing and managing pizza sales data.
- **SQL Aggregate Functions** – SUM(), COUNT(), AVG(), MAX().
- **SQL Joins** – Combining data from multiple tables.
- **Window Functions** – Ranking and cumulative revenue analysis.
- **GROUP BY & ORDER BY** – Data grouping and sorting.

## 📊 SQL Analysis & Business Questions

### 1. Basic Analysis

- Retrieve the total number of orders placed.
- Calculate the total revenue generated from pizza sales.
- Identify the highest-priced pizza.
- Identify the most common pizza size ordered.
- List the top 5 most ordered pizza types along with their quantities.

### 2. Intermediate Analysis

- Find the total quantity of each pizza category ordered.
- Determine the distribution of orders by hour of the day.
- Analyze the category-wise distribution of pizzas.
- Calculate the average number of pizzas ordered per day.
- Determine the top 3 most ordered pizza types based on revenue.

### 3. Advanced Analysis

- Calculate the percentage contribution of each pizza type to total revenue.
- Analyze cumulative revenue generated over time.
- Determine the top 3 most ordered pizza types based on revenue for each pizza category.

## 🚀 How to Run the Project

1. Clone or down

2. Extract the `pizza_sales.zip` dataset.

3. Open your preferred SQL database management system.

4. Import the pizza sales dataset into your database.

5. Review `Questions.txt` to understand the analysis requirements.
